# About
I didn't want my portfolio website to be too complex, but simple and full of personality. I moreso wanted to showcase my artistic side, with the addition of simple interactive elements that make my portfolio more like a game than a chore. 

# Built With
- HTML, CSS, JS, Bootstrap
- Ibis Paint X

# Process + Creation Photos
## 1) Parralax Scrolling + Javascript
Images were drawn in the app *ibisPaint X* and overlapped on top of one another with position: absolute. I then used js to have different images rise or fall slower than the others when scrolling, creating a parallax effect.
